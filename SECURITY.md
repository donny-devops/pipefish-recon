# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities by emailing pipefish.labs@gmail.com. 
We treat all security reports as a top priority and will acknowledge your report within 48 hours. 
Please do not report security vulnerabilities via public GitHub issues to prevent premature disclosure.
